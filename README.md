# 🛒 Project 9 – Fully E-Commerce System (JavaScript + LocalStorage)

A fully functional e-commerce web application built using only HTML, CSS, and vanilla JavaScript — no frameworks used. This project simulates real-world shopping experience with cart functionality, login system, product filters, user profile, and persistent data storage using LocalStorage.

<br/>

## 💡 Features

- 🛍️ User authentication (Login/Register)
- 🛒 Add to cart, adjust quantity, checkout
- ❤️ Add to favorites
- 🔎 Product search & category filter
- 🧾 Order history & user profile
- 🖼️ Product detail pages
- 💾 LocalStorage-based data persistence
- 📱 Responsive design without frameworks

<br/>

## 🛠️ Tech Stack

- 🔷 HTML5
- 🎨 CSS3
- 🧠 JavaScript (ES6)
- 🗂️ LocalStorage
